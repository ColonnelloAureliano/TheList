# List Ranker

Web app statica per confrontare gli elementi di cinque liste e ottenere una classifica personale.

## Modificare liste e nomi

Modifica esclusivamente `public/data/lists.json` mantenendo esattamente cinque oggetti. Ogni lista deve avere almeno due elementi.

## Pubblicazione su GitHub Pages

1. Crea un repository GitHub e carica tutti i file mantenendo le cartelle.
2. Apri `Settings > Pages`.
3. In `Build and deployment`, imposta `Source` su `GitHub Actions`.
4. Fai un commit sul branch `main`.
5. Controlla l'esecuzione nella scheda `Actions`.

## Avvio locale facoltativo

```bash
npm install
npm run dev
```
